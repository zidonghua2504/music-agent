⚙️ 智能设置

默认走本地引导引擎（离线、零成本、不依赖网络）。如需更聪明的生成式对话，可接入国内主流大模型——选服务商、填 API Key 即可使用；请求失败会自动回退本地引擎，绝不卡住学生。
开启后，由大模型接手追问与回应
选择后自动填入接口地址与默认模型，也可手动修改。各家均兼容 chat/completions 格式。
填服务商控制台开通的模型；火山方舟也可填接入点 ID（ep- 开头）。
密钥仅保存在本机浏览器（localStorage），不上传到任何第三方服务器。输入框默认空白、不会回填已保存的密钥；留空保存表示继续沿用原密钥，想更换时再填一次。
填好后点测试，会真实发一条最小请求验证 Key 与模型名是否可用。模型名失效时会自动查询该账号可用模型并纠正重试。
开启后，总结里给出更专业的技术贴士；适合有基础的使用者
默认关闭 = 零基础引导（先感知后命名）。开启不等于直接给答案，仍保留引导式提问。

⭐ 我的收藏

收藏你喜欢的曲目，随时回来听。仅保存在本机浏览器，不上传任何数据。

📜 我的聆听记录

每听完一首，会自动留下记录。点开可重听，也可删除。仅保存在本机浏览器。
